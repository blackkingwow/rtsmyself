战争迷雾系统

FogOfWar.cs / EnemyPlane.cs / UnitBase.cs
  • 世界空间 Mesh (68×46) 覆盖地图，挂载 Texture2D (512×512)
  • 每4帧：全涂黑 → 遍历友方单位 → 按视野半径"挖洞"
  • 正圆形修复：X/Z 像素比例不同 → 分别计算 rx、rz，用椭圆方程反求
  • 敌方在迷雾中：Renderer.enabled = false + Collider.enabled = false
  • 可见性查询：IsPositionRevealed() 静态方法供全局调用

导弹追踪系统

Missile.cs / MissileVehicle.cs / AntiAirMissileLauncher.cs
  • 发射：创建空 GameObject → 挂 Missile 脚本 → 加载导弹.fbx模型为子物体
  • 追踪：Quaternion.LookRotation(方向) 始终朝向目标
  • 速度 20单位/秒，命中阈值 0.8，超时 10s 自毁
  • 尾焰：ParticleSystem Cone 形状 + 橙色粒子持续喷射
  • 导弹车双模式：Q键快捷发射 + 底部栏按钮发射

波次系统 & 经济系统

波次管理 GameManager.cs

  • 20波，每波敌人数 = 波次数
  • 第一波前 15s 准备，波次间 30s
  • 每 0.3s 生成一架敌机
  • 撤退(无金币) vs 击毁(+50金) 分开处理
  • 全清 → WIN 面板

经济循环 GameManager.cs

  • 初始 1000 金
  • 每 10s 产出 20 金
  • 击杀敌机 +50 金
  • 升级公式：费用 150+n×100
  • 收入 20+n×20

技能与视觉系统

双技能

  • 骇入网络：全图视野 12s / CD 120s
  • 电磁波干扰：减速至 15% 20s / CD 180s / 200金
  • CurrentSpeed 属性动态返回减速后的速度

粒子特效链

  • 尾焰 → Cone 持续发射 (橙色)
  • 命中 → Sphere Burst 爆发 (黄色)
  • 爆炸 → 渐变色球形 (橙→红→暗)
  • 全部运行时动态创建，自动清理

技术亮点

  • 战争迷雾正圆形算法 — 纹理XY比例不同时用椭圆方程反求，保证世界空间正圆
  • 扇形避障 — 13角度扫描 + 通畅距离/方向一致性加权评分
  • 动态UI构建 — Canvas 完全由代码生成，无预制体依赖
  • Filled Image Sprite — 运行时创建1×1纹理解决血条不渲染问题
  • 序列化陷阱修复 — public字段在预制体/场景存旧值，需同步修改
  • 事件驱动架构 — UnityAction 解耦 UI 与逻辑 (OnGoldChanged/OnWaveChanged)
  • GLB/FBX 模型集成 — 嵌套Prefab挂载 + Transform旋转适配 + 材质修复
