# 地面单位碰撞系统设计

## 概述
为所有地面单位添加碰撞检测，实现部署时的位置校验和导弹车移动时的简单避障。

## 涉及的脚本改动

### 1. UnitBase.cs
- `Awake()` 中添加：如果没有 Collider，自动添加 BoxCollider，size 设为 (1.5, 1, 1.5)

### 2. UIManager.cs — HandleDeployClick 方法
- 部署前调用 `Physics.OverlapSphere(point, 2f)` 检测重叠
- 过滤掉 tag=="Enemy" 的碰撞体（敌机不阻止部署）
- 有重叠 → `ShowMessage("此处已被占用，请选择其他位置")`，不扣金币，不创建单位，不退出部署模式
- 无重叠 → 正常部署流程

### 3. MissileVehicle.cs — Update 方法
- 移动时，在前进方向做 `Physics.SphereCast(当前位置, 0.4f, 移动方向, 检测距离 0.5f)`
- 排除自身碰撞体
- 检测到障碍：分别向左前方和右前方 45° 各做一个 SphereCast（距离 0.3f）
- 选择通畅一侧，将移动方向偏移 30°，沿障碍物滑过
- 两侧都堵 → 停止移动（isMoving = false）

## 不改动的部分
- 敌机（EnemyPlane）：碰撞体保持用于点击检测，但不会成为地面碰撞的障碍
- 导弹（Missile）：无碰撞体，不受影响
- 基地/雷达站/防空发射器：静止单位，碰撞体仅用于被检测

## 验证方式
1. 部署导弹车在已有单位上面 → 应提示"被占用"且不扣金币
2. 导弹车移动穿过密集建筑群 → 应自动绕开而非穿过
3. 导弹车被完全包围 → 应停下不动
